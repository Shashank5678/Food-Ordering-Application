# 🍔 Hungry Hub

Hungry Hub is a full-stack MERN food ordering web application where users can browse food items, add them to cart, place orders, and make secure payments.

This project is built for a **single restaurant/business** (not multi-vendor).

---

## 🚀 Tech Stack

### Frontend
- React.js
- React Router
- Context API
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Payment Integration
- Stripe

---

## ✨ Features

- User authentication
- Browse food menu
- Add to cart
- Place orders
- Stripe payment integration
- Order management
- Admin dashboard
- Responsive UI

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Shashank5678/Food-Ordering-Application.git
```

### 2. Navigate into the project

```bash
cd Food-Ordering-Application
```

### 3. Install dependencies

#### Frontend

```bash
cd frontend
npm install
```

#### Backend

```bash
cd backend
npm install
```

#### Admin

```bash
cd admin
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `backend` folder.

Example:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
STRIPE_SECRET_KEY=your_stripe_secret
```

---

## ▶️ Run the Project

### Frontend

```bash
cd frontend
npm run dev
```

### Backend

```bash
cd backend
npm start
```

### Admin Panel

```bash
cd admin
npm run dev
```
